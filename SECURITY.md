# Security Policy

## Supported versions

Security fixes go into the latest release. Aviant is pre-1.0, so there are no long-term support branches.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include the affected module and version, a description of the impact, and steps or code to reproduce. You will get an acknowledgement within a few days. Once a fix is released, the advisory is published with credit to you unless you prefer otherwise.

## Dependencies

The build fails on NuGet packages with known moderate, high or critical advisories, including transitive ones, and Dependabot proposes updates weekly. If you find a vulnerable dependency that slipped through, a normal issue or PR is fine.
